# MCA Web Technology Demo

A small, beginner-friendly portfolio website for demonstrating the three core front-end technologies:

- **HTML** — page structure and semantic content
- **CSS** — styling, layout and responsive design
- **JavaScript** — events, DOM selection and page interaction

## Project files

| File | Purpose |
| --- | --- |
| `index.html` | Website content and structure |
| `style.css` | Visual design and responsive layout |
| `script.js` | Greeting interaction and mobile navigation |

## Run it locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Edit the HTML, CSS or JavaScript and refresh the browser to see your changes.

## Deploy with GitHub Pages

1. Open this repository on GitHub.
2. Select **Settings**.
3. In the left sidebar, select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**.
6. Select **Save**.
7. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages section and normally follows this pattern:

   `https://<your-username>.github.io/mca-web-technology-demo/`

## Teach the deployment workflow

```text
Write code
   ↓
Save files locally
   ↓
Commit changes with Git
   ↓
Push to GitHub
   ↓
GitHub Pages publishes the static website
   ↓
Share the live URL
```

## Classroom exercises

1. Change the name and introduction in `index.html`.
2. Change the accent colour in `style.css`.
3. Add a new skill card in the HTML.
4. Modify the greeting message in `script.js`.
5. Commit and push your changes, then refresh the deployed site.

## Important note

GitHub Pages hosts static websites (HTML, CSS and client-side JavaScript). It does not run PHP, Node.js server applications or a MySQL database.
